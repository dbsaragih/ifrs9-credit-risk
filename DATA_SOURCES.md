# Data sources and licences

No dataset is stored in this repository. Each file is downloaded into `data/raw/` (git-ignored)
and loaded by code in `src/`. This keeps the repository small and every number reproducible.

## Public track (data may be republished with attribution)

| # | Dataset | Used for | Licence |
|---|---|---|---|
| 1 | Default of Credit Card Clients (Taiwan) | Module 1 PD scorecard, Module 2b EAD/CCF | CC BY 4.0 |
| 2 | SBA 7(a) loan data (US small business loans) | Module 5 small-SME PD | US public domain |
| 3 | Synthetic datasets generated by this repository | Module 2a LGD, Module 3 lifetime PD | MIT (this repository) |

### 1. Default of Credit Card Clients (Taiwan)

- **Source:** UCI Machine Learning Repository, dataset 350:
  https://archive.ics.uci.edu/dataset/350/default+of+credit+card+clients
- **Licence:** Creative Commons Attribution 4.0 International (CC BY 4.0)
- **Content:** 30,000 credit card accounts in Taiwan, April to September 2005; 23 features;
  target = default payment in October 2005
- **File:** `data/raw/default+of+credit+card+clients.zip` (downloaded by `scripts/00_download_data.py`)

**Citation (required by the licence):**

> Yeh, I. (2009). Default of Credit Card Clients [Dataset]. UCI Machine Learning Repository.
> https://doi.org/10.24432/C55S3H

> Yeh, I. C., & Lien, C. H. (2009). The comparisons of data mining techniques for the predictive
> accuracy of probability of default of credit card clients. *Expert Systems with Applications*,
> 36(2), 2473–2480.

**Changes made:** undocumented category codes regrouped (EDUCATION 0/5/6 → "other";
MARRIAGE 0 → "other"), columns renamed, behavioural features derived. `SEX` is excluded from
modelling.

### 2. SBA 7(a) loan data

- **Source:** U.S. Small Business Administration, 7(a) & 504 FOIA data:
  https://data.sba.gov/dataset/7-a-504-foia (catalogue: https://catalog.data.gov/dataset/sba-7a-and-504-loan-data-reports)
- **Licence:** Public domain (USA.gov public domain label 1.0)
- **Content:** 7(a) loans approved since FY1991, including loan status (paid in full / charged off)
  and charge-off amounts
- **Files:** `data/raw/sba_7a_*.csv` (downloaded by `scripts/00_download_data.py`)
- **Handling:** borrower and bank names are dropped on load. Although public, they are not needed.

Suggested credit: "Source: U.S. Small Business Administration, 7(a) FOIA loan data."

### 3. Synthetic datasets

Generated by `src/synthetic.py` with fixed random seeds. They are simulated, not real borrower
data, and are released under the repository's MIT licence. They are used where no openly licensed
real data exists (loan-level recoveries for LGD; multi-year monthly loan panels for lifetime PD).

## Private track (analysis only, data never committed)

The `private/` folder is git-ignored. It holds work on datasets whose terms do not allow
republishing. Only aggregate results that cannot be used to recreate the data may be shared.

| Dataset | Used for | Terms |
|---|---|---|
| LendingClub 2007–2018 (Kaggle copy) | Consumer PD, LGD, EAD | Original LendingClub release; licence of Kaggle copies is asserted by uploaders, so treat as private |
| Freddie Mac Single-Family Loan-Level Dataset | Lifetime PD, LGD, macro adjustment | Free registration; re-posting data or derived products prohibited; research results allowed if the data cannot be recreated |
| Home Credit Default Risk (Kaggle) | Richer application scorecard (optional) | Kaggle competition rules |

## Datasets considered and not used

| Dataset | Reason |
|---|---|
| Bondora P2P (IEEE DataPort copy) | Re-uploaded by a third party; researchers using Bondora report the data cannot be made public under platform restrictions |
| Give Me Some Credit (Kaggle) | Competition rules; no advantage over Taiwan data |
| Fannie Mae loan performance | Overlaps with Freddie Mac; similar restrictions |
